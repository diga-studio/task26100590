# compliance

培训学时合规判定库（Go）。计划与学习证据保存在进程内存，由上层顺序调用。

## 能力

- `NewStore()` 创建存储；`RegisterPlan` 登记员工计划（截止时刻、各模块要求学时与最早测验通过时刻）。
- `AppendEvidence` 追加学习证据（模块 + 半开毫秒区间），允许乱序、重复、嵌套、部分重叠。
- `Query(employeeID, queryMillis)` 返回合规状态、最小总学时缺口与各模块实际计入的归属区间。

## 判定规则

- 同一毫秒最多计入一个有证据覆盖的模块；同一模块重叠证据不重复计时；各模块计入不超过其要求。
- 归属按全局最优（最大流）求解：只要存在一种合法归属满足全部模块即判学时足够，结果与证据追加顺序、重复次数无关。
- 仅使用 `min(查询时刻, 截止时刻)` 之前的学时与测验通过记录；通过时刻等于该时刻算有效。
- 全部模块学时满足且测验有效为 `StatusCompliant`；未满足时按查询时刻是否晚于截止返回 `StatusNotCompliant` / `StatusOverdue`。

## 测试

